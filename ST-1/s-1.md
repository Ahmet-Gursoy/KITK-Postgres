## 2. psql'e Bağlanma ve Veritabanı Oluşturma

```bash
docker exec -it pg-lab psql -U postgres
```

```sql
CREATE DATABASE lab;    //CREATE DATABASE = VERİTABANI OLUŞTUR --- Bu kısımda 'lab;' adında belirttğimiz şey veritabanımızın (database) adı. Yani veritabanımızın adı artık lab
\c lab // '\c lab' komutunu kullanarak oluşturduğumuz 'lab' adındaki database'e giriş yapıyoruz ve bize bir bilgilendirme mesajı geliyor.
```

```
You are now connected to database "lab" as user "postgres".
// TR: Şu anda "postgres" kullanıcısı olarak "lab" veritabanına bağlısınız.
```

## 3. İlk Tabloyu Oluşturma

```sql
CREATE TABLE kategoriler (id INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY, name TEXT NOT NULL);

// TR: 'TABLO OLUŞTUR' kategoriler '(Benzersiz bir tam sayı kimlik (id) veren birincil anahtar(PK)' name 'Metin türünde boş bırakılamayan)

SELECT * FROM kategoriler;
// TR: SEÇ * ŞURDAN kategoriler;
```

## 5. Sütun Ekleme (ALTER TABLE ... ADD COLUMN)

```sql
ALTER TABLE kategoriler ADD COLUMN fiyat NUMERIC(10,2);
//TR: TABLOYU DEĞİŞTİR kategoriler SUTÜN EKLE fiyat SAYISAL(NUMARA)(10,2);
//NUMERIC(10,2): Toplam 10 basamaklı, virgülden sonra 2 basamaklı ondalıklı sayı
//NUMERIC kuruşu tam hesaplar. REAL ya da FLOAT gibi tipler ise küçük yuvarlama hataları yapabilir (örneğin 0.1 + 0.2 tam 0.3 çıkmayabilir). Para gibi hassas değerlerde bu yüzden NUMERIC tercih edilir.

SELECT * FROM kategoriler;
```

## 6. Sütun Adını Değiştirme (RENAME COLUMN)

```sql

// TABLOYU DEĞİŞTİR kategoriler SÜTUNU YENİDEN ADLANDIR name TO yemekler
```

## 7. Veri Güncelleme (UPDATE)

```sql
UPDATE kategoriler SET fiyat = 100 WHERE id = 1;
// GÜNCELLE kategoriler SET fiyat = 100 WHERE id = 1;
 
// SET: Güncellenecek sütunu ve ona verilecek yeni değeri belirler.
// Güncelle kategoriler belirle fiyat = 100 Neresini id = 1; (İd'si 1 olanın fiyat değerini 100 olarak belirle şekilinde çevirebiliriz.)

SELECT * FROM kategoriler;
```

## 10. Düzenli Sorgulama (ORDER BY)

```sql
SELECT * FROM kategoriler ORDER BY id;
```

```
 id | yemekler  | fiyat  |  gram
----+-----------+--------+--------
  1 | Yemekler  | 100.00 | 450.00
  2 | İçecekler | 200.00 |
(2 rows)
```

```sql
UPDATE kategoriler SET gram = 150 WHERE id = 2;
// id = 2 olan sütunun gramını 150 olarak ayarlıyoruz

SELECT * FROM kategoriler ORDER BY id;
//Normalde SELECT * FROM kategoriler yapardık ve tablomuz gelirdi.
//Ama çok fazla verimiz olunca id lerin sıraları karışabiliyor bu yüzden
//ORDER BY id; yapıyoruz ki verilerimiz küçükten büyüğe gelsin

//Varsayılan olarak yapmak için komutumuzun sonunda ASC; eklememiz yeterli
SELECT * FROM kategoriler ORDER BY id ASC;

//Büyükten küçüğe getirmek için alçalan,küçülen(descending) DESC; yapmamız yeter
SELECT * FROM kategoriler ORDER BY id DESC;

```

```
 id | yemekler  | fiyat  |  gram
----+-----------+--------+--------
  1 | Yemekler  | 100.00 | 450.00        Bu şekilde düzgün bir biçimde gelir.
  2 | İçecekler | 200.00 | 150.00
(2 rows)
```

## Kullanılan Komutlar

| Komut | Görevi |
| --- | --- |
| `CREATE DATABASE` | Veritabanı oluşturma |
| `CREATE TABLE` | Tablo oluşturma |
| `INSERT INTO` | Veri ekleme |
| `SELECT` | Veri okuma |
| `ALTER TABLE ... ADD COLUMN` | Sütun ekleme |
| `ALTER TABLE ... RENAME COLUMN` | Sütun adı değiştirme |
| `UPDATE ... SET ... WHERE` | Veri güncelleme |
| `ORDER BY` | Sıralı sorgulama |
